# G5500 ESP32-S3 Controller v1.5.57

## LCD + HC-05 + DUAL CALIBRATION

Контроллер предназначен для управления антенным поворотным устройством Yaesu G-5500 по азимуту и углу места.

Текущая версия прошивки:
G5500 ESP32-S3 Controller v1.5.57 DUAL CAL POINT FLAGS FIX

Основа проекта:
- ESP32-S3-DevKitC-1 N16R8
- LCD 16x2 на HD44780
- внешний Bluetooth Classic модуль HC-05
- USB GS-232B
- Wi-Fi / TCP 4533
- Web-интерфейс
- Web-диагностика
- два независимых режима калибровки

Автор: UA1CFM

============================================================
2. LCD
============================================================

Используется LCD 16x2, совместимый с HD44780.

Подключение:

ESP32-S3      LCD
-------------------------
GPIO8   ->    RS
GPIO9   ->    E
GPIO10  ->    D4
GPIO11  ->    D5
GPIO12  ->    D6
GPIO13  ->    D7

R/W -> GND

LCD работает в 4-битном режиме.

Между ESP32-S3 и LCD используется 74HCT245 для согласования уровней.

На LCD отображаются:
- текущий AZ;
- целевой AZ;
- текущий EL;
- целевой EL.

Пример:

AZ 123 (125)
EL  45 ( 45)

Статус Bluetooth на LCD специально не выводится.
Он отображается только в Web-интерфейсе.

============================================================
3. BLUETOOTH HC-05
============================================================

ESP32-S3 не поддерживает Bluetooth Classic SPP встроенными средствами,
поэтому используется внешний модуль HC-05.

Подключение:

HC-05                ESP32-S3
--------------------------------
STATE  ------------> GPIO3
TXD    ------------> GPIO6
RXD    <------------ GPIO7
GND    ------------  GND_SYS
EN/KEY ------------  NC

UART:
9600 baud
8 data bits
No parity
1 stop bit

То есть:
9600 8N1

Важно:
TX и RX подключаются крест-накрест.

HC-05 TXD -> ESP32-S3 GPIO6 (RX)
HC-05 RXD <- ESP32-S3 GPIO7 (TX)

Вывод STATE подключён к GPIO3 и используется прошивкой для определения
Bluetooth-соединения.

В Web-интерфейсе отображается:
HC-05 Bluetooth: CONNECTED
или
HC-05 Bluetooth: DISCONNECTED

EN/KEY для обычной работы не нужен и остаётся NC.

============================================================
4. УПРАВЛЕНИЕ ПОВОРОТКОЙ
============================================================

GPIO15 -> LEFT
GPIO16 -> RIGHT
GPIO17 -> UP
GPIO18 -> DOWN

Для управления рекомендуется использовать оптопары PC817C.

Вход PC817:
GPIO -> 330 Ом -> pin 1 A
pin 2 K -> GND

Выход:
pin 4 Collector -> команда Yaesu
pin 3 Emitter   -> COMMON G-5500

============================================================
5. ОБРАТНАЯ СВЯЗЬ AZ/EL
============================================================

Аналоговая обратная связь G-5500 поступает на ADC ESP32-S3.

GPIO4 -> AZ feedback
GPIO5 -> EL feedback

Рекомендуемый входной делитель:

G-5500 feedback -> 10 кОм -> ADC
ADC -> 20 кОм -> GND
ADC -> 100 нФ -> GND

============================================================
6. ПОЧЕМУ НУЖНА КАЛИБРОВКА
============================================================

Положение поворотки определяется по аналоговому напряжению.

На точность влияют:
- нелинейность потенциометров G-5500;
- допуски резистивного делителя;
- сопротивление кабеля и контактов;
- нелинейность ADC ESP32-S3;
- механические особенности поворотки.

Поэтому прошивка использует реальные измеренные точки конкретной поворотки,
а не только простое линейное преобразование ADC -> угол.

============================================================
7. ДВА РЕЖИМА КАЛИБРОВКИ
============================================================

В v1.5.57 реализованы ровно два режима:

1. GS-232 2-POINT
2. MULTI-POINT

Данные режимов хранятся раздельно.

Переключение между режимами не стирает другой набор калибровки.

============================================================
8. GS-232 2-POINT
============================================================

Стандартная двухточечная калибровка.

Поддерживаются команды:

O
F
O2
F2

Назначение:

O   -> текущий AZ записывается как 0°
F   -> текущий AZ записывается как полный масштаб
O2  -> текущий EL записывается как 0°
F2  -> текущий EL записывается как 180°

Полный масштаб AZ определяется режимом:

P36 -> 360°
P45 -> 450°

Пример:

P36
F

записывает текущую точку как 360°.

P45
F

записывает текущую точку как 450°.

Между двумя крайними точками используется линейная интерполяция.

============================================================
9. КОНТРОЛЬ ТОЧЕК 2-POINT
============================================================

Каждая точка имеет собственный флаг сохранения:

O
F
O2
F2

Поэтому в Web-интерфейсе зелёной становится только та кнопка,
точка которой реально была сохранена.

AZ считается откалиброванным только после:
O + F

EL считается откалиброванным только после:
O2 + F2

Это исправляет ложное отображение калибровки из предыдущих версий.

============================================================
10. MULTI-POINT
============================================================

Многоточечная калибровка предназначена для компенсации нелинейности
всей измерительной цепочки.

AZ точки:

0°
90°
180°
270°
360°
450°

EL точки:

0°
45°
90°
135°
180°

В каждой точке прошивка сохраняет фактическое значение ADC.

После этого между соседними точками используется кусочно-линейная интерполяция.

Для AZ диапазон разбивается на сегменты:

0° -> 90°
90° -> 180°
180° -> 270°
270° -> 360°
360° -> 450°

Для EL:

0° -> 45°
45° -> 90°
90° -> 135°
135° -> 180°

Такой подход позволяет лучше компенсировать:
- нелинейность ADC;
- нелинейность потенциометра;
- механические отклонения;
- неидеальную характеристику обратной связи.

============================================================
11. ПРИНЦИП КОМПЕНСАЦИИ НЕЛИНЕЙНОСТИ
============================================================

В GS-232 2-POINT через весь диапазон проводится одна линейная зависимость.

В MULTI-POINT диапазон делится на несколько участков,
и каждый участок рассчитывается отдельно.

Это позволяет приблизить программную характеристику к реальной
характеристике конкретной поворотки.

Иными словами, прошивка компенсирует не только особенности ADC ESP32-S3,
но и всю измерительную цепочку:

потенциометр G-5500
        ->
кабель и контакты
        ->
резистивный делитель
        ->
ADC ESP32-S3
        ->
программная коррекция
        ->
реальный угол AZ / EL

============================================================
12. ХРАНЕНИЕ КАЛИБРОВКИ
============================================================

Калибровочные данные хранятся в энергонезависимой памяти NVS.

После выключения питания данные сохраняются.

Отдельно хранятся:
- GS-232 2-POINT;
- MULTI-POINT.

Также запоминается активный режим.

После перезагрузки контроллер возвращается в тот режим,
который был выбран перед выключением.

Для чистой установки режим по умолчанию:
GS-232 2-POINT

============================================================
13. WEB-ИНТЕРФЕЙС
============================================================

В разделе калибровки доступны:

GS-232 2-POINT
MULTI-POINT

Для GS-232 2-POINT есть кнопки:

O  — AZ 0°
F  — AZ FULL
O2 — EL 0°
F2 — EL 180°

Для MULTI-POINT доступны отдельные точки AZ и EL.

Также доступны:
- сброс AZ;
- сброс EL;
- отдельный сброс для каждого режима;
- отображение сохранённых значений ADC;
- индикация активного режима;
- зелёная индикация только реально сохранённых точек.

Основная Web-навигация:

УПРАВЛЕНИЕ
ADC TEST
RESET DIAG
DIAG CONSOLE

17. USB / HC-05 / TCP
============================================================

Команды GS-232B принимаются через:

USB
HC-05
TCP 4533

USB и HC-05 используют один и тот же GS-232B парсер.

Ответ возвращается в тот интерфейс, откуда пришла команда.

18. ИЗМЕНЕНИЯ v1.5.57
============================================================

Основные изменения:
- два независимых режима калибровки;
- GS-232 2-POINT;
- MULTI-POINT;
- команды O / O2 / F / F2;

- каждый GS-232 endpoint имеет отдельный флаг;

- MULTI-POINT полностью отделён от 2-POINT;

- статус HC-05 остаётся только в Web;
- LCD продолжает показывать только AZ / EL;
- команда Z не реализована.
