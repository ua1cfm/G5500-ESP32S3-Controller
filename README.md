YAESU G-5500 CONTROLLER на ESP32-S3
LCD-версия с HC-05 Bluetooth
Прошивка: v1.5.54
Автор: UA1CFM

============================================================
1. НАЗНАЧЕНИЕ
============================================================

Контроллер предназначен для управления антенным поворотным устройством Yaesu G-5500 по азимуту и углу места.

Основа:
ESP32-S3-DevKitC-1 N16R8

Поддерживается:
- Yaesu GS-232B;
- PSTROTATOR;
- Look4Sat / Hamlib через TCP;
- USB;
- Wi-Fi;
- внешний Bluetooth Classic модуль HC-05;
- Web-интерфейс;
- Web-диагностика;
- калибровка AZ/EL;
- LCD 16x2;
- режимы азимута 360° и 450°.

Актуальная LCD-ветка:
G5500 ESP32-S3 Controller v1.5.54
LCD + HC-05 STATE + WEB ONLY

Основа этой версии — v1.5.51 WEB_DIAGNOSTIC_CONSOLE.

============================================================
2. LCD 16x2
============================================================

Используется LCD, совместимый с HD44780, в 4-битном режиме.

ESP32-S3:
GPIO8  -> RS
GPIO9  -> E
GPIO10 -> D4
GPIO11 -> D5
GPIO12 -> D6
GPIO13 -> D7

R/W -> GND

Между ESP32-S3 и LCD используется 74HCT245:
VCC -> +5V
GND -> GND
DIR -> +5V
/OE -> GND

LCD показывает:
- текущий AZ;
- целевой AZ;
- текущий EL;
- целевой EL.

Пример:
AZ 123 (125)
EL  45 ( 45)

В версии v1.5.54 статус Bluetooth на LCD НЕ выводится.
Он отображается только в Web-интерфейсе.

3. ОБРАТНАЯ СВЯЗЬ YAESU G-5500
============================================================

Назначение линий:
pin 1 -> Elevation feedback
pin 2 -> RIGHT
pin 3 -> UP
pin 4 -> LEFT
pin 5 -> DOWN
pin 6 -> Azimuth feedback
pin 7 -> NC
pin 8 -> COMMON / GND

ADC:
GPIO4 -> AZ feedback
GPIO5 -> EL feedback

Рекомендуемый делитель:
сигнал G-5500 -> 4,7 кОм -> ADC
ADC -> 4,7 кОм -> GND
ADC -> 100 нФ -> GND

============================================================
4. УПРАВЛЕНИЕ ПОВОРОТКОЙ
============================================================

GPIO15 -> LEFT
GPIO16 -> RIGHT
GPIO17 -> UP
GPIO18 -> DOWN

Используются четыре PC817C.

Вход:
GPIO -> 330 Ом -> pin 1 A
pin 2 K -> GND

Выход:
pin 4 Collector -> команда Yaesu
pin 3 Emitter   -> COMMON

============================================================
5. BLUETOOTH HC-05
============================================================

ESP32-S3 не поддерживает Bluetooth Classic SPP встроенно, поэтому используется внешний HC-05.

HC-05 работает как прозрачный UART-мост для команд GS-232B.

Подключение:

HC-05                ESP32-S3
--------------------------------
STATE  ------------> GPIO3
TXD    ------------> GPIO6
RXD    <------------ GPIO7
GND    ------------  GND_SYS
EN/KEY ------------  NC

UART:
9600 baud
8 data bits
No parity
1 stop bit
9600 8N1

Важно:
TX и RX подключаются крест-накрест.

HC-05 TXD -> ESP32-S3 GPIO6 (RX)
HC-05 RXD <- ESP32-S3 GPIO7 (TX)

------------------------------------------------------------
STATE
------------------------------------------------------------

STATE подключён к GPIO3.

Прошивка использует этот вход для определения факта Bluetooth-соединения.

В Web-интерфейсе отображается:
HC-05 Bluetooth: CONNECTED
или
HC-05 Bluetooth: DISCONNECTED

На LCD этот статус не выводится.

------------------------------------------------------------
EN / KEY
------------------------------------------------------------

EN/KEY для обычной работы не нужен.

EN/KEY -> NC

Он нужен главным образом для входа HC-05 в AT mode.

------------------------------------------------------------
ПИТАНИЕ HC-05
------------------------------------------------------------

Проверяйте конкретную carrier board.

Многие HC-05 модули допускают питание VCC от 5 В за счёт встроенного стабилизатора, но логика UART самого модуля — 3.3 В.

Перед подключением нужно проверить маркировку конкретной платы.

------------------------------------------------------------
РАБОТА В ПРОШИВКЕ
------------------------------------------------------------

HC-05 использует отдельный аппаратный UART.

USB и HC-05 работают независимо.

Оба канала используют один и тот же GS-232B парсер.

Если команда пришла по USB, ответ возвращается по USB.
Если команда пришла по HC-05, ответ возвращается через HC-05.

============================================================
10. КАЛИБРОВКА
============================================================

Сохранена многоточечная калибровка AZ/EL.

Калибровку рекомендуется выполнить:
- при первой установке;
- после изменения делителей ADC;
- после замены поворотки;
- после механической перенастройки.

============================================================
11. ПИТАНИЕ
============================================================

ESP32-S3 и периферию нельзя питать напрямую от 13 В.

Для контроллера нужен понижающий стабилизатор.

LCD: +5 В
ESP32-S3: по требованиям DevKitC-1
HC-05: по требованиям конкретной carrier board

============================================================
12. ПРОВЕРКА HC-05
============================================================

1. Включить контроллер.
2. Сопрячь HC-05 в Android.
3. В приложении выбрать Bluetooth Classic.
4. Выбрать HC-05.
5. Нажать CONNECT.
6. Проверить, что Web показывает CONNECTED.
7. Отправить C2.
8. Проверить получение AZ/EL.
9. Выполнить небольшой тестовый поворот.
10. Проверить STOP.
