# G5500 ESP32-S3 Controller

Контроллер поворотного устройства Yaesu G-5500 на базе ESP32-S3 с TFT-дисплеем, сенсорным управлением, Wi-Fi, Bluetooth и поддержкой протокола Yaesu GS-232B.

**Версия прошивки:** 1.6.23 P36/P45 SAFE TCP COLOR  
**Файл прошивки:** `G5500_v1_6_23_P36P45_SAFE_TCP_COLOR.ino`  
**Базовая ветка:** `v1.6.23 DIAG PC TIME RECONNECT SAFE`  
**Автор:** UA1CFM

---

## Возможности

### Управление поворотным устройством

- Полная поддержка протокола **Yaesu GS-232B** через три канала связи одновременно:
  - **USB UART** (9600 бод) — для PstRotator и других GS-232-совместимых программ
  - **Wi-Fi TCP порт 4533** — для Look4Sat, Hamlib rotctld и R4UAB DDE Client
  - **Bluetooth Classic (HC-05)** — беспроводная связь с компьютером или телефоном
- **Веб-интерфейс** (HTTP порт 80) — управление, калибровка и диагностика из любого браузера
- Сенсорное управление калибровкой и движением прямо на TFT-дисплее

### Режимы азимута

- **P36** — диапазон 0..360 градусов (независимая калибровочная таблица)
- **P45** — диапазон 0..450 градусов (независимая калибровочная таблица)
- Переключение командами `P36` / `P45` или через веб-интерфейс / тачскрин
- **Живой индикатор P36/P45 на TFT**: после приёма `P36` дисплей сразу показывает `P36`, после `P45` — `P45`
- Повторная команда `P36` или `P45` также принудительно обновляет TFT, подтверждая реально активный формат GS-232B
- При смене режима азимут останавливается, устаревшая цель сбрасывается (защита от движения в недостижимую позицию)

### Калибровка

Два алгоритма калибровки, выбираются через веб-интерфейс или тачскрин:

**1. GS-232 Two-Point** (команды O / F / O2 / F2):
- `O` — текущее напряжение сенсора азимута = 0 градусов
- `F` — текущее напряжение сенсора азимута = максимум диапазона (360 или 450)
- `O2` — текущее напряжение сенсора элевации = 0 градусов
- `F2` — текущее напряжение сенсора элевации = 180 градусов
- Независимые таблицы для P36 и P45

**2. Multi-Point** (кусочно-линейная интерполяция):
- AZ P36: 5 точек (0, 90, 180, 270, 360 градусов)
- AZ P45: 6 точек (0, 90, 180, 270, 360, 450 градусов)
- EL: 5 точек (0, 45, 90, 135, 180 градусов)
- Каждая точка захватывается нажатием кнопки на тачскрине или в веб-интерфейсе
- Проверка монотонности: калибровка считается валидной только если точки идут по возрастанию (или убыванию)

### Wi-Fi

- При включении контроллер создаёт точку доступа **G5500-Rotator** (по умолчанию открытая, пароль можно задать через веб-интерфейс)
- AP IP: `192.168.4.1`
- Если в настройках сохранён SSID/пароль домашней сети, контроллер пытается подключиться один раз
- При неудаче STA полностью отключается, AP продолжает работать (SAFE-логика — точка доступа не пропадает)
- **Автоматический реконнект**: при потере связи с домашней сетью контроллер каждые 30 секунд пытается переподключиться, не блокируя управление поворотом
- Если реконнект не удался за 8 секунд — возврат в режим AP-only
- Попытка реконнекта выполняется неблокирующе: управление AZ/EL, GS-232B, TCP и веб-интерфейс продолжают обслуживаться
- После неудачной попытки STA отключается и контроллер снова гарантированно остаётся в режиме точки доступа

### Веб-интерфейс

Доступен по адресу `http://192.168.4.1` (в режиме AP) или по локальному IP (при подключении к домашней сети).

| Страница | URL | Назначение |
|---|---|---|
| Управление | `/` | Текущие азимут/элевация, цель, кнопки движения, калибровка, настройки Wi-Fi, график RSSI |
| ADC тест | `/adc` | Сырые значения ADC (raw и mV) для диагностики сенсоров |
| Диагностика сбросов | `/resetdiag` | История последних 20 перезагрузок с причиной и временем (NTP UTC) |
| Диагностическая консоль | `/diaglog` | Лог сообщений прошивки (дублирует USB Serial/JTAG) |

**API-эндпоинты:**

| Эндпоинт | Метод | Описание |
|---|---|---|
| `/api/status` | GET | JSON: текущие AZ/EL, цель, движение, калибровка, Wi-Fi, BT, IP |
| `/api/move?d=S` | GET | Управление движением (U/D/L/R/A/E/S) |
| `/api/target?az=XXX&el=YYY` | GET | Установка цели (азимут + элевация) |
| `/api/cal?p=az90` | GET | Захват точки multi-point калибровки |
| `/api/cal2?p=O` | GET | Захват two-point калибровки (O/O2/F/F2) |
| `/api/calmode?m=2` | GET | Выбор режима калибровки (2 или multi) |
| `/api/azmode?m=36` | GET | Выбор диапазона азимута (36 или 45) |
| `/api/calreset?axis=az&mode=2` | GET | Сброс калибровки по оси и режиму |
| `/api/wifi?ssid=...&pass=...` | GET | Сохранение Wi-Fi + перезагрузка |
| `/api/ap?pass=...` | GET | Установка пароля точки доступа + перезагрузка |
| `/api/adcdiag` | GET | JSON: raw/mV значения AZ и EL ADC |
| `/api/diaglog` | GET | Текст лога диагностики |
| `/api/diaglog/clear` | GET | Очистка лога |
| `/api/rssi?range=hour` | GET | JSON: история RSSI (hour/day/week/month/year) |

### TFT-дисплей

- ILI9341 320x240, горизонтальная ориентация
- **Дашборд**: текущие AZ/EL крупным шрифтом, цель, шкалы, статус калибровки/Wi-Fi/BT/IP/тачскрина, живой индикатор P36/P45
- **TCP COLOR**: IP-адрес на TFT отображается зелёным, когда к TCP-порту 4533 подключён активный клиент; без TCP-клиента используется обычный цвет текста
- **Калибровка AZ**: кнопки захвата точек (2-point или multi-point), сброс
- **Калибровка EL**: кнопки захвата точек (2-point или multi-point), сброс
- **Калибровка тачскрина**: 4-точечная калибровка XPT2046
- **Изображение кота**: полноэкранная картинка из `cat_image.h` показывается на 3 секунды после нажатия на верхний заголовок TFT; управление повороткой при этом продолжает работать
- Антифликер: перерисовка только изменившихся областей

### RGB-индикация

Встроенный адресуемый светодиод (WS2812/NeoPixel) на GPIO48:

| Цвет | Значение |
|---|---|
| Зелёный (вспышка) | Получена команда (RX) от PstRotator / Look4Sat / TCP |
| Красный (вспышка) | Отправлен ответ (TX) |
| Синий (коротко) | Heartbeat каждые 2 секунды — контроллер жив |

### Диагностика

- **Синхронизация времени** через NTP (`pool.ntp.org`, `time.nist.gov`) при подключении к Wi-Fi
- **История сбросов**: последние 20 перезагрузок с причиной (POWERON, PANIC, WDT, BROWNOUT и т.д.) и временем по UTC
- **История RSSI**: почасовая, дневная, недельная, месячная и годовая статистика уровня сигнала Wi-Fi с графиком в веб-интерфейсе
- **Диагностический лог**: ring buffer на 160 строк, доступен через USB Serial/JTAG и веб-страницу `/diaglog`

### Логика движения

- Алгоритм портирован с **LVBTrack.c** — без гистерезиса и hold-логики
- Команда `STOP` (`S`) останавливает движение, но следующая цель запускает его снова
- Ручное управление кнопками отменяет трекинг только по своей оси (AZ вручную — отменяет AZ-трек, EL вручную — отменяет EL-трек)
- Реле управления: ON/OFF, скорость фиксированная аппаратно (команды X1..X4 принимаются для совместимости, но не меняют скорость)

## Поддерживаемые команды GS-232B

### Через USB UART и Bluetooth HC-05

| Команда | Описание |
|---|---|
| `Waaa eee` | Поворот в позицию AZ=aaa, EL=eee |
| `Maaa` | Поворот только по азимуту |
| `C` | Запрос текущего азимута: `AZ=XXX` |
| `B` | Запрос текущей элевации: `EL=XXX` |
| `C2` | Запрос обеих: `AZ=XXX EL=XXX` |
| `R` / `L` | Вправо / влево (manual) |
| `U` / `D` | Вверх / вниз (manual) |
| `A` | Стоп азимута |
| `E` | Стоп элевации |
| `S` | Полный стоп |
| `O` / `F` | Калибровка AZ: 0 / максимум |
| `O2` / `F2` | Калибровка EL: 0 / 180 |
| `P36` / `P45` | Диапазон азимута 360 / 450 |
| `H` / `H2` / `H3` | Справка |

### Через TCP 4533 (rotctld / Look4Sat)

Дополнительно к командам выше:

| Команда | Описание |
|---|---|
| `p` | Запрос позиции (формат Hamlib) |
| `P az el` | Установка позиции (формат Hamlib, поддерживает десятичную запятую для R4UAB DDE) |
| `S` / `\stop` | Стоп |
| `T` | Запуск временной последовательности |
| `N` | Запрос статуса последовательности |
| `X1`..`X4` | Команда скорости (принимается, но не меняет физическую скорость) |
| `q` / `Q` | Завершение сессии |
| `_` / `\get_info` | Информация о контроллере |
| `Wttt az el az el...` | Временная последовательность: интервал ttt сек, до 16 пар AZ/EL |

## Распиновка ESP32-S3

### Дисплей ILI9341 (SPI, общая шина с тачскрином)

| GPIO | Сигнал | Назначение |
|---|---|---|
| GPIO10 | MOSI | SPI Master Out Slave In (TFT + Touch) |
| GPIO11 | SCK | SPI Clock (TFT + Touch) |
| GPIO2 | MISO | SPI Master In Slave Out (Touch) |
| GPIO12 | TFT_CS | Chip Select дисплея |
| GPIO13 | DC | Data/Command дисплея |
| GPIO14 | RST | Reset дисплея |

### Тачскрин XPT2046 (общая шина SPI)

| GPIO | Сигнал | Назначение |
|---|---|---|
| GPIO8 | TOUCH_CS | Chip Select тачскрина |
| GPIO9 | TOUCH_IRQ | Interrupt (касание) |

### Сенсоры положения (ADC)

| GPIO | Сигнал | Назначение |
|---|---|---|
| GPIO4 | AZ_ADC | Аналоговый вход сенсора азимута G-5500 |
| GPIO5 | EL_ADC | Аналоговый вход сенсора элевации G-5500 |

ADC: 12 бит, attenuation = 11 dB (диапазон ~0..3.1 В). Усреднение: 25 выборок за вызов.

### Реле управления поворотом

| GPIO | Сигнал | Назначение |
|---|---|---|
| GPIO15 | LEFT | Азимут — вращение влево (CCW) |
| GPIO16 | RIGHT | Азимут — вращение вправо (CW) |
| GPIO17 | UP | Элевация — вверх |
| GPIO18 | DOWN | Элевация — вниз |

Все выходы: LOW при загрузке (записывается до `pinMode(OUTPUT)`, чтобы исключить ложные срабатывания реле).

### Bluetooth HC-05

| GPIO | Сигнал | Назначение |
|---|---|---|
| GPIO6 | RX | ESP32 RX ← HC-05 TXD |
| GPIO7 | TX | ESP32 TX → HC-05 RXD |
| GPIO3 | STATE | Состояние подключения HC-05 (HIGH = подключён) |

Скорость: 9600 бод, UART1.

> **Внимание:** GPIO3 — strapping pin на ESP32-S3. Рекомендуется внешний pull-down на этой линии, чтобы HC-05 не мешал загрузке при включении.

### RGB-светодиод

| GPIO | Сигнал | Назначение |
|---|---|---|
| GPIO48 | RGB | WS2812 / NeoPixel (или `RGB_BUILTIN`, если определён платой) |

Яркость по умолчанию: **5/255**, задаётся строкой `static const uint8_t RGB_LEVEL = 5;` и может быть изменена в диапазоне 0..255.

### USB

| Интерфейс | Назначение |
|---|---|
| UART0 USB | PstRotator / GS-232, 9600 бод (COM-норт назначается Windows) |
| Native USB Serial/JTAG | Диагностика, прошивка (COM-норт назначается Windows) |

## Схема подключений

### Дисплей ILI9341 2.8" (320x240) с тачскрином XPT2046

```
ESP32-S3          ILI9341
GPIO10  --------> MOSI (SDI)
GPIO11  --------> SCK
GPIO2   <-------- MISO (SDO, только тачскрин)
GPIO12  --------> CS
GPIO13  --------> DC
GPIO14  --------> RST
3.3V   --------> VCC / LED
GND    --------> GND

ESP32-S3          XPT2046
GPIO8   --------> CS (T_CS)
GPIO9   <-------- IRQ (T_IRQ)
                    MISO, MOSI, SCK — общие с TFT
```

### Сенсоры G-5500

```
ESP32-S3          G-5500 сенсор
GPIO4   <-------- AZ (азимут, аналоговый выход 0..~3.3 В)
GPIO5   <-------- EL (элевация, аналоговый выход 0..~3.3 В)
GND     --------> общая земля
```

> Сенсоры G-5500 выдают напряжение, пропорциональное углу. Убедитесь, что диапазон напряжения сенсора не превышает 3.3 В (при необходимости — делитель).

### Реле управления

```
ESP32-S3          Реле / драйвер
GPIO15  --------> AZ LEFT (CCW)
GPIO16  --------> AZ RIGHT (CW)
GPIO17  --------> EL UP
GPIO18  --------> EL DOWN
GND     --------> общая земля
```

> GPIO подключаются к модулю реле или транзисторному драйверу, который замыкает соответствующие контакты G-5500 (как кнопки на пульте управления).

### Bluetooth HC-05

```
ESP32-S3          HC-05
GPIO6 (RX) <------ TXD
GPIO7 (TX) -------> RXD (через делитель 3.3В -> 5В, если HC-05 питается от 5В)
GPIO3     <------ STATE
3.3V/5V   -------> VCC (зависит от модуля HC-05)
GND       -------> GND
```

> Линия RXD HC-05 толерантна к 3.3 В, но если HC-05 питается от 5 В, сигнал TX с ESP32 желательно подавать через делитель. Линия TXD HC-05 выдает 3.3 В — безопасна для ESP32 напрямую.

## Состав проекта для GitHub

Минимальная структура папки скетча должна выглядеть так:

```text
G5500_v1_6_23_P36P45_SAFE_TCP_COLOR/
├── G5500_v1_6_23_P36P45_SAFE_TCP_COLOR.ino
├── cat_image.h
└── README.md
```

`cat_image.h` обязателен: прошивка содержит `#include "cat_image.h"` и использует массив RGB565 для вывода полноэкранной картинки кота. Без этого файла компиляция завершится ошибкой.

При желании рядом можно хранить исходное изображение-превью, например:

```text
cat_preview.png
```

Оно **не участвует в компиляции** и предназначено только для просмотра на GitHub.

> Важно: имя основной `.ino` и имя папки Arduino-скетча должны совпадать. Для совместимости с программами и файловыми системами рекомендуется использовать короткие имена файлов — менее 63 символов.

### Что добавлено именно в этой сборке

По отношению к базовой `v1.6.23 DIAG PC TIME RECONNECT SAFE` в этой сборке дополнительно есть:

- живое подтверждение последней принятой команды `P36` / `P45` на TFT;
- немедленная перерисовка индикатора диапазона при смене режима;
- сохранение независимых калибровок AZ для P36 и P45;
- **TCP COLOR** — цвет IP-адреса на TFT отражает наличие активного TCP-клиента на порту 4533;
- сохранена безопасная автоматическая переподключаемость к домашнему Wi-Fi;
- сохранена работа в режиме AP-only, если домашняя сеть недоступна;
- сохранено изображение кота через `cat_image.h`;
- сохранены USB GS-232B, HC-05, TCP 4533, Web UI, Touch и обе системы калибровки.

## Настройка

1. Прошейте ESP32-S3 скетчем через Arduino IDE
2. При первом включении контроллер создаст точку доступа **G5500-Rotator** (открытую)
3. Подключитесь к Wi-Fi сети `G5500-Rotator`
4. Откройте браузер по адресу `http://192.168.4.1`
5. Введите SSID и пароль вашей домашней Wi-Fi сети, нажмите "Save Wi-Fi + reboot"
6. После перезагрузки контроллер подключится к домашней сети; IP-адрес отображается на TFT-дисплее
7. При необходимости задайте пароль для точки доступа (8..63 символа, WPA2)

### Калибровка

1. Откройте страницу `/` в веб-интерфейсе или перейдите к калибровке на TFT-тачскрине
2. Выберите режим: **GS-232 2-POINT** или **MULTI-POINT**
3. Выберите диапазон: **P36** (360) или **P45** (450)
4. Для 2-point: поверните антенну в 0 градусов, нажмите `O`. Поверните в максимум, нажмите `F`. Аналогично для элевации — `O2` (0) и `F2` (180)
5. Для multi-point: поверните антенну в каждую указанную позицию и нажмите соответствующую кнопку
6. Статус калибровки отображается на TFT-дисплее и в веб-интерфейсе (зелёный = валидна)

### Калибровка тачскрина

На TFT-дисплее: долгое удержание (3 секунды) в центре экрана запускает 4-точечную калибровку XPT2046. Данные сохраняются в NVS.

## Подключение внешних программ

### PstRotator (USB)

1. Подключите ESP32-S3 к компьютеру по USB
2. В PstRotator выберите тип поворотного устройства: **Yaesu GS-232B**
3. Выберите COM-порт (назначается Windows при подключении USB)
4. Скорость: **9600**

### PstRotator (Bluetooth)

1. Сопрягите HC-05 с компьютером
2. В PstRotator выберите COM-порт Bluetooth
3. Скорость: **9600**

### Look4Sat (Android, Wi-Fi)

1. Подключите телефон к той же Wi-Fi сети, что и контроллер
2. В Look4Sat настройте rotctld: IP-адрес контроллера, порт **4533**
3. Протокол: **GS-232B**

### Hamlib rotctld (Linux/macOS/Windows, Wi-Fi)

```bash
rotctld -m 601 -r <IP_контроллера>:4533
```

где `601` = GS-232B в таблице моделей Hamlib.

### R4UAB DDE Client (Windows, Wi-Fi)

Поддерживается десятичная запятая в команде `P` (автоматическая замена `,` на `.`). Настройте TCP-подключение к IP контроллера, порт 4533.

## Практические замечания

### Индикация P36 / P45

Индикатор на TFT показывает **текущий активный диапазон азимута**, установленный последней командой GS-232B или выбранный через интерфейс:

```text
P36 -> 0...360°
P45 -> 0...450°
```

При переключении меняется не только надпись на дисплее, но и используемый набор калибровочных данных AZ.

### Цвет IP при TCP-подключении

Когда клиент Look4Sat, Hamlib, R4UAB DDE Client или другая программа подключена к TCP-порту `4533`, прошивка определяет состояние `rotctldClient.connected()` и выделяет IP-адрес на TFT зелёным цветом. После отключения клиента цвет возвращается к обычному.

Это позволяет визуально видеть наличие активной сетевой сессии без открытия диагностической страницы.

### Плавного регулирования скорости в этой версии нет

Эта ветка предназначена для штатного **ON/OFF управления через GPIO15..18 и оптопары/реле**. Команды `X1..X4` принимаются для совместимости GS-232B, но не изменяют физическую скорость поворотки.

Экспериментальные версии с внешним PWM-драйвером и плавным стартом/торможением являются отдельной веткой и в эту стабильную сборку не включены.


## Сохраняемые данные (NVS)

Все настройки хранятся в энергонезависимой памяти ESP32-S3 и не теряются при отключении питания:

- Wi-Fi SSID и пароль
- Пароль точки доступа
- Калибровка AZ (P36 и P45 раздельно)
- Калибровка EL
- Режим калибровки (2-point / multi-point)
- Режим диапазона (P36 / P45)
- Калибровка тачскрина
- История сбросов (до 20 записей с временем UTC)
- Годовая история RSSI

## Диагностика и типичные проблемы

### TFT работает, но картинка кота не компилируется

Проверьте, что `cat_image.h` лежит в той же папке, что и основной `.ino`:

```cpp
#include "cat_image.h"
```

### P36/P45 не меняется на экране

Проверьте, что используется именно эта сборка. В ней обработчики `P36` и `P45` вызывают переключение `gsAzMode`, а TFT принудительно перерисовывается после команды.

### Домашний Wi-Fi пропал

Контроллер продолжает поднимать собственную сеть `G5500-Rotator`. Через 30 секунд запускается новая попытка подключения к сохранённой домашней сети; каждая попытка ограничена 8 секундами. При неудаче контроллер возвращается в AP-only.

### IP на TFT стал зелёным

Это штатное поведение сборки **TCP COLOR**: зелёный IP означает, что к TCP 4533 в данный момент подключён клиент.

### Реле кратковременно срабатывают при загрузке

В прошивке выходные защёлки GPIO15..18 предварительно устанавливаются в LOW до `pinMode(OUTPUT)`, чтобы уменьшить риск ложного включения. Тем не менее силовую часть рекомендуется проектировать с аппаратным безопасным состоянием входов.
